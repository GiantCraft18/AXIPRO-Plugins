## Installation

1. Open the required plugin directory.
2. Select the version compatible with your client.
3. Download the plugin file.
4. Install it using your plugin manager.
5. Restart the client if required.

## Security

Only download plugins from trusted AXIPRO sources. Review permissions and compatibility before installation.
